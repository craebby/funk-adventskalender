## Experiment: Die Hitliste der Störer

Für die Zahlen im Monitor muss der Uno am PC bleiben. Also kommen die Geräte zum Schreibtisch: Ladegerät,
Laptop-Netzteil, Schreibtischlampe, Föhn lassen sich alle in die Steckdosenleiste am PC stecken. Was sich nicht
tragen lässt, testest du mit der Powerbank wie an Tag 9: Je höher der Ton, desto stärker der Störer.

Halte den Draht jeweils etwa 5 cm vor das Gerät, während es läuft, und schreib die höchste Zahl auf:

| Gerät | Stärke |
|---|---|
| Handy-Ladegerät | |
| Laptop-Netzteil | |
| LED-Lampe | |
| Föhn | |
| Fernseher | |
| … | |

Wer gewinnt? Und was passiert, wenn das Gerät aus ist, aber noch in der Steckdose steckt?

## Übrigens

Viele Netzteile schalten innen zehntausende Male pro Sekunde, um klein und sparsam zu sein. Das strahlt ab.
Damit sich die Geräte nicht gegenseitig stören, gibt es Grenzwerte, und für Funkamateure ist genau das ein
Dauerthema: Billige Netzteile können den Empfang im ganzen Haus verrauschen.
